Changes by RS Advanced contributors:
- Replace hotbar selection and global inventory/configuration state with generic menu commands.
- Limit layout to a full circle and derive radius from the available GUI size.
- Combine angular selection with inner and outer deadzones.
- Add command labels, selected/disabled state, live status and validity checks.
- Use the shared Minecraft screen renderer on Fabric and NeoForge.
The three original slot textures are unmodified.
